# 💪 Muscle Mart

Muscle Mart is a simple fitness and gym-wear e-commerce website that I developed as a **BCA 4th Semester project**.

The main idea behind this project is to create a website where people interested in fitness can easily browse gym clothes, accessories, and other fitness-related products.

## 📌 About the Project

I created Muscle Mart to practice and apply the frontend web development concepts I have learned during my BCA course.

The website focuses on keeping the design simple, clean, and easy to use. It includes a fitness-themed design along with product sections and basic interactive features.

## ✨ Features

* Clean and simple homepage
* Fitness and gym-focused design
* Product display section
* Search functionality
* Interactive elements using JavaScript
* Custom Muscle Mart logo
* Simple and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure of the website
* **CSS3** – Used for styling and designing the pages
* **JavaScript** – Used to add interactive functionality

## 📂 Project Structure

```text
Muscle-Mart/

```

### Files

* **script.js** – Handles the JavaScript functionality
* **logo.png** – Muscle Mart logo

## 🚀 How to Run

You don't need to install anything complicated to run this project.

1. Clone this repository:

```bash
git clone https://github.com/Samirpdl03/Muscle-Mart.git
```

2. Open the `Muscle Mart` folder.
3. Open `index.html` in your browser.

You can also open the project in **VS Code** and use the Live Server extension while developing.
